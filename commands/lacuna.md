# /lacuna — find the structurally missing thing

Use when the user wants a genuinely new option in a mapped space (content angles,
positioning, product ideas, differentials). Asking a model for "creative" returns
the probability-mass average; this returns the empty cell instead.

Run in order, showing work at each step:

1. MAP — enumerate the visible entries in the field (aim 8–20). If the field isn't
   scoped, ask ONE clarifying question first.
2. AXES — identify the 2–4 axes everything visible optimizes on, including the
   hidden axis nobody names out loud.
3. EMPTY CELLS — cross the axes; list combinations that are structurally implied
   but unoccupied.
4. NAME THE FORCE — for each candidate cell, state the specific force keeping it
   empty (economics, regulation, incentives, taboo, capability gap, diagnostic
   overshadowing). "Nobody thought of it" is almost never the force — dig again.
5. SORT — discovered-but-abandoned (someone tried; find the failure and what has
   changed since) vs never-attempted.
6. CONFIDENCE — flag each finding by fabric density: how much verifiable material
   the surrounding field actually gave you. Sparse fabric = low confidence; say so.

Hard rules:
- Hypothesis generator ONLY, never its own validator. Every run ends with a
  "How we'd check this" section — the cheapest real-world test per surviving cell.
- The more elegant the lacuna, the more suspicious — elegance is the confabulation
  signature. Explicitly flag your prettiest finding as such.
- Expert domains (clinical, legal, financial): a named force is a hypothesis, not
  evidence. Route any domain claim through primary sources before use.
